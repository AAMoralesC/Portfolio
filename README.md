## ✨ Características

- 📱 **Mobile-First Responsivo:** Diseño fluido que se adapta perfectamente a cualquier tamaño de pantalla.
- 🌗 **Modo Oscuro/Claro:** Soporte nativo para cambio de tema con persistencia en `localStorage`.
- 🌐 **Bilingüe (ES / EN):** Contenido completamente traducido al español e inglés, con cambio de idioma en tiempo real.
- 🎬 **Animaciones Fluidas:** Transiciones, efectos de hover y scroll-reveal implementados con Framer Motion.
- ⚡ **Rendimiento Extremo:** Construido sobre Vite + React 19, con bundle optimizado y assets cacheados con `immutable`.
- 🔍 **SEO Optimizado:** Meta etiquetas completas, Open Graph y Twitter Card para previsualizaciones ricas al compartir.
- 🔒 **Hardening de Seguridad:** Cabeceras HTTP configuradas en Vercel (CSP, HSTS, X-Frame-Options, CORS, etc.) validadas con OWASP ZAP.

## 🚀 Cómo ejecutar en local

Si deseas clonar el proyecto para revisarlo o usarlo como inspiración, sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/AAMoralesC/Portfolio.git
   ```

2. **Entrar al directorio:**
   ```bash
   cd Portfolio
   ```

3. **Instalar dependencias:**
   ```bash
   npm install
   ```

4. **Levantar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

La aplicación estará disponible en `http://localhost:5173`.
